# airdrop-faucet-bot

Multi-chain faucet and airdrop claim automation

Works on **Windows / macOS / Linux**. No account, no signup, no telemetry.

```bash
npm install airdrop-faucet-bot
npx airdrop-faucet-bot --help
```

## Why this one

- single command, no daemon
- reads your local wallet files (Phantom, Solflare, MetaMask keystore)
- supports batch mode over a CSV of addresses
- dry-run by default, `--live` to execute
